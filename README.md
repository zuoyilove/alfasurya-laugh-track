A single one-line joke about crypto trading life: buying the dip, only for the dip to buy a shovel and keep digging. It is written for traders who have watched a "bargain" turn into rent on a hole — short, clean, and built around a setup and a turn that lands on a feeling every bag-holder recognises.

The joke's target is the dip-buyer himself, not the market: the laugh comes from recognising your own trade in the hole, not from watching someone else fall in.

## Run it

```sh
node main.ts
```
